## 合并标准

1. 使用发布包，默认选择 W 驱动，版本和边界明确。
2. 独立测试用户/schema、表空间、凭据，未触碰来源测试库或其他会话对象。
3. 实际第三方 API 的实库验证；并发、事务、恢复等按该库的契约检查；明确执行、失败和跳过数。
4. 指定 Astra High 审查完成，实质问题修复并验证。
5. 主会话检查差异及证据，合并到 main 后进行组合构建和必要的集成复验。

隔离测试库位于已有达梦实例内，通过各自的用户/schema 与表空间隔离；并未为每库部署新的达梦服务器实例。所有凭据保存在忽略的本地配置中。
